# Juego de vocabulario

Página estática para practicar vocabulario con imágenes verticales, temporizador de 1 minuto y opciones aleatorias.

## Cambiar las imágenes

Añade tus imágenes en la carpeta `images/` con estos nombres, o cambia las rutas en `script.js`:

- `hacer-fotos.jpg`
- `descansar.jpg`
- `ir-a-la-playa.jpg`
- `ir-a-un-museo.jpg`
- `ir-de-excursion.jpg`
- `ir-a-un-concierto.jpg`

El juego funciona aunque las imágenes todavía no existan: muestra tarjetas provisionales sin revelar la respuesta.

## Ajustes rápidos

En `script.js` puedes cambiar:

- `GAME_SECONDS`: duración del juego.
- `OPTIONS_PER_ROUND`: número de botones por ronda.
